# Hanko

Лёгкое и удобное десктопное приложение для чтения манги/манхвы и просмотра аниме, созданное для комфортного личного использования.

## Возможности

* 📖 **Манга и манхва:** Удобный поиск и чтение тайтлов прямо в приложении.
* 🎬 **Аниме:** Смотрите аниме в приложении Hanko.
* 👥 **Друзья и чат:** Возможность добавлять друзей по нику и общаться в реальном времени.

## Установка
