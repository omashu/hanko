# Hanko

Лёгкое и удобное десктопное приложение для чтения манги/манхвы и просмотра аниме, созданное для комфортного личного использования.

## Возможности

* 📖 **Манга и манхва:** Удобный поиск и чтение тайтлов прямо в приложении (без необходимости скачивать файлы на диск).
* 🎬 **Аниме:** Быстрый доступ к любимым сайтам через встроенный браузер в виде удобных плиток.
* 👥 **Друзья и чат:** Возможность добавлять друзей по нику и общаться в реальном времени (на базе Supabase).
* 🔄 **Автообновление:** Приложение умеет самостоятельно проверять наличие новых версий через GitHub Releases.
